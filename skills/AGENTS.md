# Skills

1. Read the target skill's `SKILL.md`, README, and change protocol before
   editing it.
2. Run, resume, inspect, explain, verify, review, or apply through the
   `waygent` CLI (`bun run waygent -- …`). Do not load `skills/_legacy/waygent`.
3. Do not load `skills/_legacy/` unless the user names that path.
4. Keep skill docs, evals, and advertised commands in sync.
5. Skills do not redefine Waygent product ownership.
