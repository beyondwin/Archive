## Boundary helpers (D001 / D002)

Paired state-write + AgentLens-emit boundaries are bundled into single calls so a
prose step can no longer be silently skipped:

| Helper / subcommand | Bundles |
|---------------------|---------|
| `phase_boundary.py task-start` | `current_pre_task_sha` + `timing.started` (hard-fail) |
| `phase_boundary.py task-complete` | result write + `timing.completed` + `last_completed_task`/`_at` + `kws-cme.task_completed` emit |
| `phase_boundary.py phase-emit --type phase_0_started` | emit + `timestamps.started_at` setdefault |
| `phase_boundary.py phase-emit --type compaction` | emit only (no timestamp) |
| `phase_boundary.py phase-emit --type phase_2_complete` | emit + `timestamps.completed_at` overwrite |
| `state_set.py --field … --plan-scope {active\|run}` | atomic, flock-protected, `<active>`-resolving field write |

`check_skill_contract.py`'s V221 block verifies the phase references invoke each
of these (`phase_boundary_*_wired`, `state_set_wired`).

## Active-tree resolution (post-D004)

| State.json shape | `<active>` |
|------------------|-----------|
| `plan_chain` present (multi-plan) | `state.plan_chain[state.active_plan]` (integer index) |
| Otherwise (single-plan) | `state` (top-level, `active_plan == "plan1"`) |

`scripts/migrate_legacy_state.py` rewrites a legacy `plan2_state`-shaped state.json
into the `plan_chain` shape at Phase 0 Step 0 before any `<active>` logic runs, so
no live state.json reaching Phase 1 carries `plan2_state`. `validate_method_audit.py`
keeps `plan2_state` *read* support for historical archive replay only.

## `mode` enum at ship time

`state.mode ∈ {interactive_session, headless_pending, headless_running,
headless_chained, plan_chain_running, plan2_running}`. `plan_chain_running` is
written by the Phase 2 Step -1 Cross-Plan Trigger; `plan2_running` is the legacy
equivalent preserved (not rewritten) by the migration shim.
