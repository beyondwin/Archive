# History

## 4.0.0 - 2026-07-13

CPE 4 is an intentional breaking simplification.

- Replaced the schema-3 plan harness with a durable schema-4 queue for one or
  many approved Superpowers plans and optional specification documents.
- Added immutable input generations, lossless document and program mapping,
  content-addressed accepted publications, exact task briefs, standing
  autonomy, and six explicit authority boundaries.
- Replaced the long-lived coordinating model with fresh bounded mapping, task,
  review, investigation, fix, document-audit, and final-integration roles.
- Serialized write-capable roles in one isolated worktree and bound every
  successful handoff, audit, verification, and terminal artifact to Git
  evidence.
- Made resume replay the manifest, private artifacts, event chain, worktree,
  and child handoffs without redispatching completed work.
- Reduced active verification to six credential-free standard-library checks
  covering contracts, mapping, queue, final closure, recovery, and CLI/export.
- Added bounded per-case eval process groups and TERM/grace/KILL cleanup, plus
  crash-safe append-only tombstone retention for complete unselected mapping
  publications while permanently protecting every event-selected artifact.
- Deleted the superseded release, live-provider, certification, compatibility,
  plan-parser, task-packet, projection, repair-tool, and historical eval
  surfaces from the active skill.

Existing schema-3 run directories are preserved. CPE 4 can inspect a bounded
summary but cannot migrate or resume them. The complete schema-3 implementation,
documentation, and earlier release history remain available in Git history
before 4.0.0.
